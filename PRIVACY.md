# Privacy Policy — Trakisilo

Trakisilo is an offline-first desktop application.

- All data (tasks, clips, time entries) is stored **locally on your device** in a local database.
- The application collects **no personal data**, performs **no telemetry or analytics**, and transmits nothing over the network.
- There are **no accounts, no cloud sync, and no third-party data sharing**.
- The application makes no network requests except optional installer downloads at install time.

Contact: open an issue at https://github.com/nkunal1992/trakisilo-releases/issues
